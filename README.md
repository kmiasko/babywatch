# babywatch

Watches a nanny-cam stream and notifies when the baby is **upright (sitting or standing) in the crib**.
Nothing is sent while the crib is empty or an adult is in view.

Pipeline: crib ROI (ORB + homography against reference frames) → frozen DINOv2/SigLIP2 embedding → small
classifier (`lying` / `upright` / `empty`) → hysteresis, gated by a YOLO person detector (any person who is not
the baby inside the crib suppresses notifications for 5 s).

## Install

CUDA build of PyTorch (cu128), Python 3.12:

```fish
uv tool install ./dist/babywatch-0.1.0-py3-none-any.whl --python 3.12 -c requirements.lock \
    --index https://download.pytorch.org/whl/cu128 --index-strategy unsafe-best-match
# or into a venv with pip:
pip install -c requirements.lock dist/babywatch-0.1.0-py3-none-any.whl \
    --extra-index-url https://download.pytorch.org/whl/cu128
```

`requirements.lock` pins the tested versions (torch 2.11 + CUDA 12.8). Without it the resolver may pick a newer
torch built for CUDA 13. Regenerate it with `uv export --no-hashes --no-emit-project -o requirements.lock`.

For development in this directory: `uv sync`, then `uv run babywatch ...`.

## Data directory

The package contains code only. All data lives in `~/.babywatch` (override with `set -x BABYWATCH_HOME /path`):

```
~/.babywatch/
  config/scenes.yaml        camera positions: reference frame + crib polygon (babywatch set-roi)
  refs/*.png                reference frames ("ref" paths in scenes.yaml are relative to ~/.babywatch)
  models/upright.joblib     classifier head + hysteresis (babywatch train)
  models/yolo11m.pt         person detector for the adult gate
  labels/intervals.csv      posture labels (training only)
  labels/adult.csv          adult-in-view intervals (training only)
  labels/sheets/, review/   generated by `sheets` / `review`
  cache/                    embeddings + person boxes (training only)
  recordings/*.mp4, *.mkv   clips (training only; if two share an id, the longer one is used)
```

Every path option (`--model`, `--scenes`, `--labels`, `--cache`, `--out`, ...) still accepts an explicit path.

## Commands

```fish
babywatch live --rtsp 'rtsp://USER:PASS@CAMERA/stream' --log events.jsonl [--show]
babywatch live --file ~/.babywatch/recordings/clip.mp4 --realtime
babywatch set-roi --name pos_e --rtsp 'rtsp://...'     # add a camera position

# retraining after adding recordings + labels
babywatch sheets            # contact sheets for labeling
babywatch review --pred ~/.babywatch/cache/preds.npz
babywatch cache-embeddings --configs dinov2_b@224 siglip2_b@224
babywatch cache-persons
babywatch train --configs dinov2_b@224 siglip2_b@224
```

`live` prints one JSON line per notification change:
`{"ts": "...", "notify": true, "state": "upright", "adult": false, "p": 0.99}`.
